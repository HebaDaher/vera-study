# VERA — Graduation Project Teaching Tool

Interactive, animated study tool for **VERA: A Verifiable, Human-Confirmed Platform for Reproducible AI-Assisted Research Data Analysis** (Canadian University Dubai, 2026–2027).

Covers: problem & pilot study · literature & research gap · competitor comparison · solution & LLM boundary · Scrum-based methodology & gates · high-level architecture · all UML diagrams (use case, activity A/B, sequence, component, class, state machine) · prototype walkthrough · team & timeline · examiner Q&A, flashcards and quiz.

**Open it:** https://hebadaher.github.io/vera-study/

## Interactive prototype (demo)

Clickable HCI prototype of VERA's full workflow — upload, study declaration (AI draft + confirmation), declaration-vs-data check, data preparation, Rule Engine & Assumption Gate (ANOVA blocked, Kruskal–Wallis admissible), override, guided question, confirmation gate, results with a downloadable JSON analysis record, qualitative coding demo, Verifier and Administrator views. Single HTML file, mocked data, all logic simulated in the browser.

**Open it:** https://hebadaher.github.io/vera-study/prototype/

## Web UI prototype v2 (walkthrough-aligned)

Five-screen researcher workflow for a before/after training study, aligned with the VERA research walkthrough: upload and describe (AI draft must be confirmed), confirm the study design, method checks against rules R01–R08 (Paired t-test, Welch's t-test, Linear regression, Use the eligible method), approve and run, results with a downloadable decision record and verifier replay. Includes a synthetic missing-exam sensitivity demo. Single HTML file; AI draft and backend are simulated and labelled.

**Open it:** https://hebadaher.github.io/vera-study/prototype-v2/
